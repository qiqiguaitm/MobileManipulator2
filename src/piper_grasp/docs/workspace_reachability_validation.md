# Piper 机械臂工作空间可达性验证报告

> 生成时间: 2026-01-25
> 验证脚本: `scripts/_cc_workspace_validation.py`

## 1. 概述

本报告验证 Piper 6-DOF 机械臂从观察位置下降到抓取深度的工作空间可达性。

### 1.1 测试结论

| 验证模式 | 执行方式 | 标准范围可达率 | 扩展范围可达率 |
|---------|---------|---------------|---------------|
| 连续航点验证 | Segmented MoveJ (近似直线) | **100%** | **99.8%** |
| 端点验证 | MoveJ (曲线) | 99.96% | 96.3% |

**推荐**: 使用 **Segmented MoveJ** 执行下降动作，可达率最高且路径可控。

### 1.2 有效工作空间

```
标准工作空间 (推荐):
  X: 300 ~ 600 mm
  Y: -200 ~ 200 mm
  Z: 0 ~ -250 mm (相对于 Z=150mm 起始)
  Yaw: 90° ~ 270°
  可达率: 100%

扩展工作空间 (边界):
  X: 200 ~ 700 mm
  Y: -300 ~ 300 mm
  Z: 50 ~ -350 mm
  Yaw: 45° ~ 315°
  可达率: 99.8%
```

## 2. 运动模式说明

### 2.1 三种运动方式对比

| 运动类型 | 插值空间 | 笛卡尔路径 | 特点 |
|---------|---------|-----------|------|
| **MoveL** | 笛卡尔空间 | 直线 | 路径精确，但有奇异点问题 |
| **MoveJ** | 关节空间 | 曲线 | 可靠快速，但路径不可控 |
| **Segmented MoveJ** | 关节空间(分段) | 近似直线 | 兼顾可靠性和路径可控性 ✓ |

```
MoveL (真正直线):
起点 ════════════════════════════════> 终点
              笛卡尔空间直线
              ⚠️ 奇异点附近会失败

Segmented MoveJ (分段曲线，近似直线):
起点 ~~>~~>~~>~~>~~>~~>~~>~~>~~>~~>~~> 终点
     ↑   ↑   ↑   ↑   ↑   ↑   ↑   ↑
   每段60mm小弧线，整体近似直线
   ✓ 推荐使用

MoveJ (曲线):
起点 ╭─────────────────────────────╮ 终点
              关节空间插值产生的曲线
              ⚠️ 路径不可控
```

### 2.2 为什么 Segmented MoveJ 可达率最高？

**关键: IK 配置分支连续性**

```
端点验证 (MoveJ) - 可能失败:
起点 IK ──────────────────> 终点 IK
配置A                        配置B (不同分支!)
     └─── 关节跳跃 60° ────┘ → 失败

连续航点验证 (Segmented MoveJ) - 成功:
起点 ──> 航点1 ──> 航点2 ──> ... ──> 终点
配置A    配置A'   配置A''          配置A'''
     └─8°─┴──8°──┴── ... ──8°──┘ → 成功
```

每个航点使用上一点的 IK 解作为种子，保证配置分支连续，避免大幅关节跳跃。

## 5. 实用建议

### 5.1 推荐配置

```yaml
# piper_grasp_node.yaml
grasp:
  use_segmented_descent: true    # 使用 Segmented MoveJ ✓
  descent_segment_size: 60       # 每段 60mm
  use_movel_descent: false       # 不使用 MoveL (有奇异点问题)

working_area:
  yaw_min: 90                    # 支持 90°~270°
  yaw_max: 270
```

### 5.2 场景选择

| 场景 | 推荐执行方式 | 原因 |
|------|-------------|------|
| 常规抓取 | Segmented MoveJ | 100% 可达，路径近似直线 |
| 深度抓取 (Z<-250mm) | Segmented MoveJ | 连续 IK 种子保证可靠性 |
| 边界位置 (X<300mm) | Segmented MoveJ | 端点验证在此区域失败率高 |
| 快速移动 (非抓取) | MoveJ | 速度更快，但路径不可控 |

### 5.3 注意事项

1. **避免使用 MoveL**: 虽然是真正直线，但在奇异点附近会失败
2. **边界位置调整 Pitch**: X<300mm 时可能需要 Pitch=5°~15°
3. **Yaw 范围**: 实际支持 45°~315°，但建议使用 90°~270° 更稳定
