**日期**: 2026-02-25
**版本**: v1.0

---

## 1. 背景调研

### 1.1 双相机融合目标

采用双相机匈牙利匹配融合的目标有两个：
1. **盲区补充**：让Chassis相机补充Top相机的视觉盲区，扩大有效感知范围
2. **协同增强**：让两个相机协同工作，对于重叠视野内的物体通过多视角观测获得更精确的感知能力

### 1.2 现有方案问题

原有的双相机融合采用**简单距离聚类**方法：
- 遍历所有检测结果，计算两两之间的3D距离
- 距离小于阈值的归为同一簇
- 取簇内置信度最高的结果

**存在的问题**：
- 贪心策略，非全局最优
- 可能将同一相机的不同物体错误聚合
- 缺乏类别兼容性考虑

### 1.3 匈牙利算法优势

匈牙利算法（Hungarian Algorithm）是解决**二分图最优匹配**的经典算法：
- 时间复杂度 O(n³)，对于典型场景（N≤20）仅需 ~12ms
- 保证全局最优匹配
- 可自定义代价函数，融合多种判定规则

## 2. 设计

### 2.1 整体架构

```
┌─────────────────┐    ┌─────────────────┐
│  Chassis Camera │    │   Top Camera    │
│   Detections    │    │   Detections    │
└────────┬────────┘    └────────┬────────┘
         │                      │
         ▼                      ▼
    ┌────────────────────────────────┐
    │    Object3D → DetectionWithDepth    │
    │         (数据格式转换)              │
    └────────────────┬───────────────┘
                     │
                     ▼
    ┌────────────────────────────────┐
    │      DualCameraMatcher         │
    │  ┌──────────────────────────┐  │
    │  │   CostFunction (代价计算) │  │
    │  │   - 3D距离 (60%)         │  │
    │  │   - 类别兼容性 (40%)     │  │
    │  └──────────────────────────┘  │
    │  ┌──────────────────────────┐  │
    │  │   HungarianMatcher       │  │
    │  │   (scipy.linear_sum_assignment) │
    │  └──────────────────────────┘  │
    │  ┌──────────────────────────┐  │
    │  │   MatchFuser (结果融合)   │  │
    │  └──────────────────────────┘  │
    └────────────────┬───────────────┘
                     │
                     ▼
    ┌────────────────────────────────┐
    │  输出: matched + unmatched     │
    │  - 匹配对 → 融合位置           │
    │  - 未匹配 → 直接保留           │
    └────────────────────────────────┘
```

### 2.2 代价函数设计

**综合代价** = `0.6 × 距离代价 + 0.4 × 类别代价`

| 组件 | 计算方式 | 说明 |
|------|---------|------|
| 距离代价 | `dist_3d / threshold` | 归一化到 [0,1]，超过阈值返回 ∞ |
| 类别代价 | 相同=0, 兼容=0.3, 不兼容=1.0 | 支持相似类别表 |

**硬门控**：
- 距离阈值: 20cm（超过直接判定不可匹配）
- 最大代价阈值: 0.7（超过不建立匹配）

### 2.3 匹配质量评估

| 等级 | 条件 | 置信度加成 |
|------|------|-----------|
| EXCELLENT | dist<5cm, 类别兼容 | +0.15 |
| GOOD | dist<10cm, 类别兼容 | +0.10 |
| ACCEPTABLE | dist<20cm | +0.05 |
| POOR | 其他 | +0.00 |

### 2.4 融合策略

匹配成功的物体对：
- **位置**: 两个相机位置的简单平均
- **类别**: 取置信度高的相机结果
- **检测分数**: 取两者最大值
- **置信度**: 基于匹配质量加成

## 3. 实现

### 3.1 核心代码修改

**文件**: `multi_camera_perception_node.py`

#### 3.1.1 初始化匹配器

```python
# 融合配置（匈牙利匹配器参数）
self.declare_parameter('fusion_distance_threshold', 0.2)  # 20cm
self.declare_parameter('fusion_max_cost', 0.7)
self.declare_parameter('fusion_weight_distance', 0.6)
self.declare_parameter('fusion_weight_category', 0.4)

self._dual_camera_matcher = DualCameraMatcher(
    weight_distance=fusion_weight_distance,
    weight_feature=0.0,  # 当前不使用视觉特征
    weight_category=fusion_weight_category,
    distance_threshold=self.fusion_threshold,
    max_cost_threshold=fusion_max_cost,
)
```

#### 3.1.2 融合流程

```python
def _fuse_results(self, results):
    # 1. 转换数据格式
    chassis_dets = [self._object3d_to_detection(obj, 'chassis') for obj in chassis_objects]
    top_dets = [self._object3d_to_detection(obj, 'top') for obj in top_objects]

    # 2. 匈牙利匹配
    matches, unmatched_c_idx, unmatched_t_idx = self._dual_camera_matcher.matcher.match(
        chassis_dets, top_dets
    )

    # 3. 处理匹配对
    for match in matches:
        fused_obj = self._fuse_matched_pair(chassis_objects[match.chassis_idx],
                                            top_objects[match.top_idx], match)
        fused.objects.append(fused_obj)

    # 4. 保留未匹配项
    for idx in unmatched_c_idx:
        fused.objects.append(chassis_objects[idx])
    for idx in unmatched_t_idx:
        fused.objects.append(top_objects[idx])
```

## 4. 遇到的问题

### 4.1 Numpy 数组布尔判断问题

**现象**: `ValueError: The truth value of an array with more than one element is ambiguous`

**原因**:
```python
# 错误写法
bbox=np.array(obj.bbox) if obj.bbox else np.array([0,0,0,0])
# obj.bbox 是数组，if 判断会失败
```

**修复**:
```python
if bbox is not None and len(bbox) >= 4:
    bbox_arr = np.array(bbox[:4], dtype=np.float32)
else:
    bbox_arr = np.array([0, 0, 0, 0], dtype=np.float32)
```

### 4.2 Dataclass 的 index() 方法失败

**现象**: 在列表中查找包含 numpy 数组的 dataclass 对象时失败

**原因**: `list.index()` 依赖 `__eq__`，而 numpy 数组的 `==` 返回布尔数组而非标量

**修复**: 不使用 `index()` 查找，直接使用匹配器返回的索引
```python
# 错误: idx = chassis_dets.index(det)
# 正确: 直接使用 unmatched_c_idx
for idx in unmatched_c_idx:
    fused.objects.append(chassis_objects[idx])
```

### 4.3 RViz 订阅 QoS 不匹配

**现象**: RViz 节点收不到 fused 话题数据

**原因**:
- 发布端使用 `TRANSIENT_LOCAL` 持久化
- 订阅端使用默认 `VOLATILE`

**修复**:
```python
from .utils import LATCHED_QOS

self._fused_sub = self.create_subscription(
    Object3DArray, fused_topic, self._fused_objects_callback, LATCHED_QOS
)
```

### 4.4 导入遗漏

**现象**: `NameError: name 'LATCHED_QOS' is not defined`

**修复**:
```python
from .utils import CvBridgeNumPy2 as CvBridge, parse_pointcloud2_fast, LATCHED_QOS
```
