# 双相机3D定位精度实验方案

## 1. 实验目的

1. 分别测量 Chassis 和 Top 相机在不同距离下的测距精度
2. 在共视区对比两个相机的测量误差
3. 为后续融合策略提供参考数据

## 2. 相机配置

| 参数 | Chassis Camera | Top Camera |
|------|---------------|------------|
| 型号 | RealSense D435 | RealSense D455 |
| 高度 | 17.1cm | 57.8cm |
| 朝向 | 向下俯视38° | 水平(略下4°) |
| 推荐距离 | 20-100cm | 60-160cm |

## 3. 实验设置

### 3.1 准备工具
- 卷尺或激光测距仪
- 测试物体：水瓶（高约20cm）
- 标记胶带（标记测量点）

### 3.2 启动命令

```bash
# 单独测试 Chassis 相机
ros2 launch perception_bringup multi_camera_3d_rviz.launch.py \
    enable_top:=false enable_chassis:=true auto_detect_rate:=0.0

# 单独测试 Top 相机
ros2 launch perception_bringup multi_camera_3d_rviz.launch.py \
    enable_top:=true enable_chassis:=false auto_detect_rate:=0.0

# 双相机同时测试
ros2 launch perception_bringup multi_camera_3d_rviz.launch.py \
    enable_top:=true enable_chassis:=true auto_detect_rate:=0.0
```

### 3.3 手动触发检测

```bash
ros2 service call /multi_camera_perception/detect \
    perception_interfaces/srv/DetectObjects "{prompt: 'bottle'}"
```

## 6. RViz中读取的信息

每个检测目标的文本标签显示：
```
bottle_1                  ← 物体ID
dist:1.25m               ← base_link距离 (用于对比)
[chassis] z=1.15m        ← 来源相机 + 深度
opt:(0.12,-0.05,1.15)    ← optical坐标
```

**主要对比项**：`dist` 值与手动测量的距离

---

## 7. 测量流程

1. **放置物体**：用卷尺测量物体底部中心到机器人base_link的距离
2. **触发检测**：调用检测服务或等待自动检测
3. **读取结果**：在RViz中查看距离标签的 `dist:x.xxm` 值
4. **记录数据**：填入表格，计算误差

---

## 8. 预期时间

| 阶段 | 点位数 | 时间 |
|------|-------|------|
| Chassis相机 | 12点 | 40分钟 |
| Top相机 | 12点 | 40分钟 |
| 双相机共视区 | 9点 | 30分钟 |
| **总计** | 33点 | 约2小时 |

---

## 9. 注意事项

1. **测量基准**：距离从 base_link（底盘中心）测量到物体底部中心
2. **物体摆放**：确保物体正对相机，标签朝向不影响检测
3. **等待稳定**：放置物体后等待2-3秒再触发检测
4. **多次验证**：关键点位可重复2-3次取平均

---

## 10. 结果分析建议

1. **按距离绘图**：X轴为真实距离，Y轴为误差，观察趋势
2. **确定可信区间**：找出相对误差<5%的距离范围
3. **融合阈值**：共视区内两相机差值的均值，可作为匹配阈值参考
